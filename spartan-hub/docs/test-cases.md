## 三、Bug 总结

### Bug-01: 新增成员后，费用管理无法识别（**用户报告**）
- **严重程度**：🔴 严重（核心功能异常）
- **根因**：`openItemModal()`、`renderAdminExpense()`、`renderAdminHub()`、`exportCsv()` 中硬编码了 `['m1','m2','m3','m4','m5','m6']`
- **影响**：成员管理界面与费用管理界面数据未联动，新增的成员无法被分摊费用

### 修复方案
将 4 处硬编码改为动态遍历 `SPARTAN_HUB.users` 过滤 `role !== 'admin'`。

### 修复明细

```javascript

const memberIds = ['m1','m2','m3','m4','m5','m6'];

// 修复后
Object.entries(SPARTAN_HUB.users)
  .filter(([_, u]) => u.role !== 'admin')
  .map(...)
```
